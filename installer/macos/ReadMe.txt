Service Dashboard

Drag Service Dashboard onto Applications.

Node.js 18 or newer has to be installed first.

The first time macOS blocks the app, right-click Service Dashboard, choose Open, and confirm. The app is not signed with an Apple certificate.

On a Mac, the service list and the security page use sample data. Controlling real Windows services, and collecting firewall and login data, happens on the Windows server. Install ServiceDashboard-Setup.exe there. Site checks from this Mac are real.

Settings, history, and logs for the Mac app are kept in:

  ~/Library/Application Support/Service Dashboard
